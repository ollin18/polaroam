# Examples

<div class="grid cards" markdown>

-   :material-earth:{ .lg .middle } **Example data, end to end**

    ---

    11.3M pings from 500 devices in five cities over two years: stays, trajectories, speeds,
    modes and home / work, with every figure and the code that makes it.

    [:octicons-arrow-right-24: Example data](example-data.md)

-   :material-city-variant:{ .lg .middle } **Mexico City at scale**

    ---

    One month, 1.66 billion pings, 1.58M devices: city-wide stays, homes, work places and
    21M trajectories, all at once and day by day; streets per mode, a check against the official
    travel survey, and routines that complete partial trips.

    [:octicons-arrow-right-24: Mexico City](mexico-city.md)

</div>

!!! note "Privacy"
    Both datasets contain real people's locations. Every map in this documentation is an
    **aggregate** over many devices (densities, overlaid lines). Single-trip illustrations are
    drawn in a relative frame (km from an arbitrary origin) or without coordinates, a basemap or
    their first and last kilometre, so no individual location is disclosed.
